## Acceptance Criteria Checklist

Mark each item done only with objective evidence.
When implementing a new acceptance criteria:
- Check if it interferes with already defined acceptance criteria
  - if it does ask the user what to do
  - if it does not interfere add it to the list bellow as acceptance criteria

## Acceptance criteria
1. Unconfigured forms fill with type-based random values.
2. Popup lists all forms in the current DOM.
3. User can save current form values as a named fill.
4. User can configure per-field override type.
5. Number fields support min/max, excluded values, decimals.
6. Text fields support predefined values.
7. Config persists by URL/form identity and supports auto-seed.
8. Named fills can be selected and applied for the form.
9. Overlay icon appears on every detected form (top-left).
10. Config can be exported/imported as JSON.
11. Overlay icon is not shown for forms with zero interactive fields.
